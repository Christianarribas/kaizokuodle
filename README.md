# Kaizokuodle (copia personal, version movil)

Copia personal del juego **Kaizokuodle** de [madrefoka](https://github.com/madrefoka/Kaizokuodle)
(https://madrefoka.github.io/Kaizokuodle/), con el diseno arreglado para verse bien en movil.

- El repositorio original **no indica licencia**; esta copia es solo para uso personal.
- Todo el credito del juego, los datos y las imagenes es del autor original.
- Cambios respecto al original: unicamente maquetacion responsive de la tabla de resultados
  (scroll horizontal usable, celdas compactas en pantallas pequenas) y empaquetado en un solo
  archivo HTML autocontenido. La logica y los datos del juego son identicos.

Jugar: https://christianarribas.github.io/kaizokuodle/
